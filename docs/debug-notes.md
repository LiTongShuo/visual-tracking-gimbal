# 调试与优化记录

## 问题背景

本项目来自视觉追踪云台的多轮实机调试。初始版本能够识别画面中的靶标并输出 YAW/PITCH 控制量，但在连续旋转舵机、视觉噪声和目标丢失场景下容易出现过冲、抖动或突然乱甩。

## 主要问题与处理

| 问题 | 表现 | 整理后的处理方式 |
| --- | --- | --- |
| YAW 连续舵机过冲 | 小误差下仍持续旋转，目标容易被甩出画面 | 使用软件 PWM，将平均速度转换为短脉冲占空比，并在中心死区内清零 |
| PITCH 累加失控 | 视觉线程慢、电机控制快时，角度偏移被反复累加 | 使用画面 Y 方向误差到角度的绝对映射，并用平滑系数逐步逼近 |
| 目标丢失后乱甩 | 置信度不足时仍继续输出控制量 | 低置信度时冻结 PITCH、YAW 输出 0 |
| 舵机未使能时积累误差 | `servo off` 期间后台继续计算，重新使能后突然动作 | 控制器在未使能时直接冻结当前输出 |
| 线程间共享状态 | 视觉、控制和终端命令同时读写状态 | 使用 `SharedState` 和锁封装快照读写，测试并发更新场景 |

## 自动测试边界

当前测试覆盖不依赖摄像头和真实云台的逻辑：控制限幅、软件 PWM、状态并发读写、命令解析、FakeGimbal 硬件隔离和视觉辅助函数。真实设备验证仍需要 Linux、V4L2 摄像头、双轴云台和 `wiringpi` 环境。
