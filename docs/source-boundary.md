# 来源与公开边界

本仓库由本地 `视觉追踪云台调试与优化 - Google Gemini.html` 调试记录整理而来。原始导出文件包含多轮代码修改、调试讨论和页面资源，不作为公开项目核心代码提交。

## 整理原则

- 保留可核验、可测试的工程逻辑：视觉辅助函数、控制策略、线程安全状态、硬件隔离和命令解析。
- 删除或改写只适用于临时调试的页面导出内容。
- 将真实硬件依赖封装在 `WiringPiGimbal` 中，默认测试使用 `FakeGimbal`。
- README 与简历表述只描述当前仓库能支撑的能力。

## AI 协作说明

项目代码和文档基于既有调试记录进行工程化重组，并在整理过程中使用 AI 协助生成测试、文档和模块结构。最终公开内容以本仓库源码和自动化测试为准。
