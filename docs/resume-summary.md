# 简历项目条目参考

## 推荐项目名称

视觉追踪云台调试与控制系统

## 简历表述

基于 Python / OpenCV 整理并工程化实现双轴视觉追踪云台控制项目，硬件环境为 Orange Pi 5 Pro 8G、720p USB 摄像头、MG90S 舵机 x 2 和 3D 打印自制云台。系统通过摄像头识别靶标中心偏差与目标距离，并转换为 YAW/PITCH 舵机控制指令。项目将视觉识别、控制算法、硬件输出和终端调试命令拆分为可测试模块，使用线程安全共享状态协调视觉线程、控制线程和命令输入。

## 可放入简历的要点

- 使用 OpenCV 完成图像预处理、轮廓筛选、靶标中心定位和 PnP 距离估计，支持无硬件环境下的辅助函数测试。
- 针对自制云台舵机过冲问题，实现 YAW 软件 PWM、中心死区、速度限幅和扫描模式。
- 针对 PITCH 轴累加失控问题，改为视场角绝对映射和平滑缓动，并在低置信度或舵机未使能时冻结输出。
- 使用 `threading.Lock` 封装共享状态，降低视觉、控制和终端命令线程之间的数据竞争风险。
- 建立 pytest 自动化测试和 GitHub Actions，覆盖控制算法、线程安全、命令解析、硬件模拟和视觉辅助函数。

## 公开边界

本项目可证明 Python、OpenCV、设备控制、多线程状态管理、调试优化和自动化测试实践。当前仓库不声明 gRPC/Protobuf、Appium 或 UIAutomation2 经验。
